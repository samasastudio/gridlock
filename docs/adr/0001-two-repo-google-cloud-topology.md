# 0001: Two-Repo Google Cloud Topology (`gridlock` Workspace + `profile-site` Host)

Gridlock consolidates all backend ingestion, self-healing repair, stateful image synthesis, runtime API routes (`/api/*`), and embeddable UI widgets into a single npm workspace repository (`gridlock`), while `profile-site` remains a clean personal website and blog on Firebase Hosting within the same Google Cloud project. Inside `gridlock`, `packages/core` runs on Google Cloud Run (Cloud Run Jobs for scheduled ingestion/repair/painting and a Cloud Run Service for `/api/*`), and `packages/widgets` (`@samasastudio/gridlock-widgets`, developed in isolation with Storybook) exports self-contained React widgets (`<GridlockPlateWidget />`, `<GridlockConsoleWidget />`, `<GridlockRepairLogWidget />`) that `profile-site` mounts with a single component import.
