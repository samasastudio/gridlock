# 0004: Clean Architecture Four-Layer Module Layout in `packages/core`

To prevent ticket-shaped monolith files that mix domain models, constants, transport adapters, and orchestration, `@samasastudio/gridlock-core` (`packages/core/src`) is organized into four top-level layer directories behind the public `src/index.ts` barrel: `interfaces/` (Zod schemas, TypeScript models, external adapter contracts, constants, and seed defaults), `use-cases/` (business workflows and pure deterministic functions under `use-cases/helpers/`), `adapters/` (repository, HTTP/Playwright loaders, and Cloud Logging implementations), and `controllers/` (HTTP route handlers and server dispatch). Dependencies point strictly inward (`controllers/` & `adapters/` -> `use-cases/` -> `use-cases/helpers/` -> `interfaces/`), repository adapters delegate state transitions (heal amortization, MTTR averaging, and quarantine retention promotion) to pure functions in `use-cases/helpers/`, and `scripts/lint-checks.mjs` enforces a `<= 300`-line ceiling and inward import rules across all `packages/core/src/**/*.ts` files.
