# 0004: Clean Architecture Four-Layer Module Layout in `packages/core`

To prevent ticket-shaped monolith files that mix domain models, constants, transport adapters, and orchestration, `@samasastudio/gridlock-core` (`packages/core/src`) is organized into four top-level layer directories behind the public `src/index.ts` barrel: `controllers/` (HTTP route handlers and request/response serialization), `use-cases/` (business workflows plus pure deterministic functions under `use-cases/helpers/`), `adapters/` (repository persistence, HTTP/Playwright loaders, and Cloud Logging implementations), and `interfaces/` (Zod schemas, TypeScript models, external adapter contracts, constants, and seed defaults). Dependencies flow strictly top-down (`controllers/` -> `use-cases/` (+ `use-cases/helpers/`) -> `adapters/` -> `interfaces/`), use cases own all domain state transitions (heal amortization, MTTR averaging, and quarantine retention promotion) via `use-cases/helpers/telemetry-math.ts` before persisting via `adapters/`, and `scripts/lint-checks.mjs` enforces a `<= 300`-line ceiling and layer import rules across all `packages/core/src/**/*.ts` files.
