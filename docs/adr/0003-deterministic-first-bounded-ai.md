# 0003: Deterministic-First Execution with Bounded Gemini Interactions API Agents

Routine data plumbing, content-hash idempotency, delta calculation, and UI component rendering execute in 100% deterministic TypeScript code with zero LLM token consumption. Gemini models (accessed directly via the official `@google/genai` Interactions API) are strictly bounded to three high-leverage boundaries: (1) the out-of-band Repair Agent (`gemini-3.8-flash`) when a Connector breaches an invariant, (2) the Stateful Painter Agent (`gemini-3-pro-image` / Nano Banana Pro via `previous_interaction_id` image chaining) when new Observations cross a meaningful visual milestone, and (3) the Generative UI Investigation Planner (`gemini-3.8-flash`) translating natural-language queries into a Zod-validated UI AST. Because deterministic gates prevent redundant model calls and all generated Visual Plates are cached in Cloud Storage, using `gemini-3-pro-image` delivers maximum visual precision and brand consistency with negligible token volume.
